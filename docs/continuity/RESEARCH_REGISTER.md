# RESEARCH REGISTER — findings and the decisions they drove

Traceability rule: research that changes nothing is not repeated. Every entry names
the decision or design it fed. Full reports live in the project research workspace
(`ai-platform-research/`, 2026-11-13) and are summarised here.

| Research | Key finding | Decision / design it drove |
|----------|-------------|----------------------------|
| Capability inventory (repo-grounded) | ZERO of 18 frontend modules has backend support; frontend AI is 100% scripted; no domain tables exist. | **Domain persistence precedes any real cross-module AI.** Roadmap order (vendors → evidence → assessments) exists because of this. |
| Competitor matrix (7 vendors × 13 dims) | Incumbent autonomy claims collapse against their own docs (SecurityScorecard's help centre disclaims autonomous action; Archer's TPRM agents are roadmap). Real contradiction detection in only 3 of 7. Nobody publishes agent accuracy evidence. | Differentiation targets: evaluation transparency, deterministic scoring, verification (NORTH_STAR). Marketing claims are never treated as shipped capability. |
| Model evaluation (TPRM workloads) | Anthropic: strongest contract posture (no-training term, ZDR by agreement; Fable/Mythos and Batch are ZDR-excluded). OpenAI: best measured structured-output reliability. Gemini Developer API retains data 55 days with no ZDR path. | Decision D7 (provider strategy) + the 20-case evaluation suite design with hard gates (fabricated citation / invented score / injection compliance = disqualified). |
| Proactive gap analysis (13 vendors × 10 dims) | Continuous monitoring is ALREADY ESTABLISHED (not a differentiator). Trajectory outlooks genuinely unexplored. **Independent agent verification absent at all 13 vendors.** The Foresight+Graph+Simulator combination is undelivered but an integration-only moat (12–24-month window). | Roadmap steps 11, 13, 14, 16 and their ordering; NORTH_STAR differentiation list. Foresight is positioned as a combination, never as "we monitor vendors." |
| Foresight data-source & licensing assessment (21 sources) | Safe free foundation: GLEIF (CC0), SEC EDGAR, CISA KEV/NVD/EPSS, official sanctions lists, GDELT Project. **Trap: OpenSanctions data is CC BY-NC** — commercial screening use breaches it. News-API free tiers are evaluation-only licences. | Decision D9 (source-of-record ingestion; own sanctions matching). Foresight F1 (roadmap step 10) builds only on the safe list. |
| Foresight design study | Of 9 proposed new responsibilities, only 2 are genuinely agents (Preventive Action Planner, Independent Verification Agent); the rest are deterministic services, jobs and tools. **The engine has no scheduler/system-actor — a hidden prerequisite for all proactive work.** Confirmed/unconfirmed must be a data state (a KEV entry cannot join to a vendor until a product-use edge exists). | Roadmap steps 9–16 sequencing; Decision D10; V12 vendors schema amended pre-commit to capture legal name / LEI / jurisdiction. |
| Agent-engine concurrency audit (PR #3) | Fenced claims, atomic plan persistence, lock-then-check heartbeat renewal (V11) — and the explicit residual: a renewal-path outage ≳ lease can expire a live claim. | The external-write gate (D5) is stated in terms of provider idempotency, not engine safety. Audit: `backend/docs/agents/AGENT-ENGINE-CONCURRENCY-AUDIT.md`. |
| Logto M0 live verification | ES384-strict tenant; API resources are NOT on Logto Free production (Pro required). | Open decision O2. M1 remains paper-only and unauthorised. |
